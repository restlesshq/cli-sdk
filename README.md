# Restless CLI plugins

Drop-in `feedback` commands for the CLI frameworks API companies ship with. Each one lets your CLI's users, and the coding agents driving it, send a note straight to your Restless dashboard.

| framework | package | |
| --- | --- | --- |
| [oclif](https://oclif.io) | [`@restlessai/oclif-plugin-feedback`](./oclif) | available |
| anything else in Node | [`@restlessai/cli-feedback`](./core) | available, with a prompt your coding agent can follow |

More frameworks are coming. Until yours has its own package, `@restlessai/cli-feedback` works with any Node CLI. Each lives in its own directory with its own README.
